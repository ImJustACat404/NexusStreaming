**Nexus Streaming** is a secure, real-time streaming service built in Python. It allows users to share their **live camera**, **screen**, and **microphone audio**, encrypted end-to-end for privacy. Designed with a simple and intuitive graphical interface using the **Pygame** library.

## 🔒 Features

- 📹 **Live Camera Streaming**  
- 🖥️ **Screen Sharing**
- 🎙️ **Microphone Audio Streaming**
- SQLite3 Databse for user data
- 🔐 **End-to-End Encryption**
  - AES (Advanced Encryption Standard) for data encryption
  - RSA for secure key exchange
- 🧩 Built with **Python**
- 🎮 Interface created using **Pygame**

## 📦 Installation

### Requirements

- Python 3.10+
- pip
